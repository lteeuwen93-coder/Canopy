# Canopy — Landing Page Concept

A single-file, responsive one-page landing page concept for a fictional AI company ("Canopy") positioned around nature, greenery, and future technology. Built as a self-contained HTML file with embedded CSS and JavaScript — no build tools or dependencies required.

## Structure
- `index.html` — the full landing page (hero, vision statement, technology pillars, photo band, stats, contact CTA, footer)

## Usage
Open `index.html` directly in a browser, or host it on any static file host (GitHub Pages, Netlify, Vercel, etc.).

## Notes
- Copy, brand name, and stats are placeholder content for concept/portfolio purposes.
- Imagery is sourced from free-to-use Unsplash photos; swap for licensed or AI-generated visuals before using this in a real deliverable.
